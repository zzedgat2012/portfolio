# Story 2.5: CV page and PDF

- Epic: Epic 2: Pages
- Status: review

## Story

As a recruiter, I want a printable CV generated from the site, so that I can download an up-to-date PDF.

## Acceptance criteria

1. `/cv/` per `CV (PDF, A4)` mockup from profile: name, role, location • phone • website, Summary (bio), Skills, Experience (company, role, range), Education, Certifications, footer `edgar-ferreira.com • Generated from the site`; light print theme; A4 `@page` with margins; `noindex`.
2. Build step (D4) writes `out/edgar-ferreira-cv.pdf` (A4) from `/cv/`; the build fails if the PDF cannot be produced.
3. Home "Download CV" downloads it (`download` attribute); file name `edgar-ferreira-cv.pdf`.
4. Playwright: `/cv/` content from fixtures; the PDF responds 200 with `application/pdf`.

## Dev notes

- **Route**: `apps/web/src/app/cv/page.tsx`, outside the `(site)` group, so no header/nav/footer; its own `<main data-theme="print">`. `metadata.robots = { index: false }` (`<meta name="robots" content="noindex">`), title `CV | <siteName>`. Exports to `out/cv/index.html`.
- **Feature** `features/cv`: `toCv(profile, settings)` (model `Cv`: contact line `location • phone • website`, skills joined with `•`, experience `company/role/dateRange`, certifications `<year> · <title>`, footer `<siteUrl host> • Generated from the site`) and `CvSheet` component. `toWebsiteLabel` moved from `features/home/model` to `shared/lib` (used by home and cv; no cross-feature deep import).
- **Light print theme**: new tokens `paper/ink/ink-muted/ink-rule` in the `globals.css` `@theme`, all taken from the existing DESIGN.md palette (#FFFFFF, #121212, #3D3D3D, #A8A8A8). `:root:has([data-theme="print"])` remaps the semantic colors (`background`, `foreground`, `muted-foreground`, `accent`, `border`, `ring`), so shared components (Markdown) render dark-on-white unchanged. **Deviation to flag to UX**: DESIGN.md has no print/light theme section; the mockup greys (~#555–#777) are rendered with `#3D3D3D` (closest palette value with AA contrast). Bio `**bold**` renders in Fira Code bold per the DESIGN.md prose rule, the mockup shows plain text.
- **A4**: `app/cv/print.css` (`@page { size: A4; margin: 15mm }`) is imported only by the CV page; verified its CSS chunk is not linked from `/`.
- **PDF (D4)**: `apps/web/scripts/postbuild.ts` runs after `next build` (`build` = `next build && tsx scripts/postbuild.ts`). Steps are `PostbuildStep { name, run(context: { outDir }) }`, run in order by `runPostbuildSteps` (logs `postbuild ▸/✓ <name>`; first failure throws `PostbuildStepError`; the runner exits 1). `cv-pdf` step: `node:http` static server on 127.0.0.1:0 serving `out/`, Playwright Chromium (from `@playwright/test`, no second browser) prints `/cv/` with `format: 'A4', printBackground: true, preferCSSPageSize: true` to `out/edgar-ferreira-cv.pdf`, then checks the `%PDF-` signature. Real content gives 2 A4 pages (MediaBox 594.96 × 841.92 pt); fixtures give 1.
- **File name**: `CV_PDF_FILE_NAME` / `CV_PDF_PATH` / `CV_PAGE_PATH` in `apps/web/src/features/cv/model/cv-pdf.ts` (dependency-free; exported via `@/features/cv`, imported directly by `scripts/cv-pdf-step.ts`, which runs outside Next). Home "Download CV" has `download="edgar-ferreira-cv.pdf"`.
- **Build/tooling**: `tsx@4.23.15` added to web devDependencies (same pin as the migrator); `deploy` is now `pnpm run build && wrangler deploy` so deploys include the PDF; vitest includes `scripts/**/*.test.ts`, tsconfig includes `scripts/**/*.ts`; biome's CLI `noConsole` override extended to `apps/web/scripts/**`. Turbo `build` inputs already cover `scripts/` via `$TURBO_DEFAULT$`; outputs already include `out/**`.

# Story 2.5: CV page and PDF

- Epic: Epic 2: Pages
- Status: ready-for-dev

## Story

As a recruiter, I want a printable CV generated from the site, so that I can download an up-to-date PDF.

## Acceptance criteria

1. `/cv/` per `CV (PDF, A4)` mockup from profile: name, role, location • phone • website, Summary (bio), Skills, Experience (company, role, range), Education, Certifications, footer `edgar-ferreira.com • Generated from the site`; light print theme; A4 `@page` with margins; `noindex`.
2. Build step (D4) writes `out/edgar-ferreira-cv.pdf` (A4) from `/cv/`; the build fails if the PDF cannot be produced.
3. Home "Download CV" downloads it (`download` attribute); file name `edgar-ferreira-cv.pdf`.
4. Playwright: `/cv/` content from fixtures; the PDF responds 200 with `application/pdf`.

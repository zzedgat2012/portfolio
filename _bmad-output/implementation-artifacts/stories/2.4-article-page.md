# Story 2.4: Article page

- Epic: Epic 2: Pages
- Status: ready-for-dev

## Story

As a visitor, I want to read articles with readable code samples, so that I can learn from them and share them.

## Acceptance criteria

1. `/article/<slug>/` statically generated for every article; unknown slugs 404.
2. Per `Artigo` mockups: "Back to articles" (`/#articles`), tag chips, title (h1), date (`December 19, 2025`, `<time datetime>`), reading time ("15 min"), author block (portrait, name, role).
3. Body rendered from Markdown per D3: headings, lists (styled markers), blockquote, inline code, fenced code highlighted at build with filename header when `title=` meta present and a working Copy button (client component, accessible name).
4. "Share this article": Twitter/X and LinkedIn share URLs with the canonical article URL, and "Copy Link".
5. Author card "Written by <name>" with bio line and "Read more articles" (`/#articles`).
6. Playwright: rendering of each element from a fixture article containing every Markdown feature; copy button copies; share links correct.

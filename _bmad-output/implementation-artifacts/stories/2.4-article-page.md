# Story 2.4: Article page

- Epic: Epic 2: Pages
- Status: review

## Story

As a visitor, I want to read articles with readable code samples, so that I can learn from them and share them.

## Acceptance criteria

1. `/article/<slug>/` statically generated for every article; unknown slugs 404.
2. Per `Artigo` mockups: "Back to articles" (`/#articles`), tag chips, title (h1), date (`December 19, 2025`, `<time datetime>`), reading time ("15 min"), author block (portrait, name, role).
3. Body rendered from Markdown per D3: headings, lists (styled markers), blockquote, inline code, fenced code highlighted at build with filename header when `title=` meta present and a working Copy button (client component, accessible name).
4. "Share this article": Twitter/X and LinkedIn share URLs with the canonical article URL, and "Copy Link".
5. Author card "Written by <name>" with bio line and "Read more articles" (`/#articles`).
6. Playwright: rendering of each element from a fixture article containing every Markdown feature; copy button copies; share links correct.

## Dev notes

Implemented 2026-11-08 following AGENTS.md directly (`/bmad-build` could not load: `uv` missing).
`external/` was not read.

**Built**
- Route `apps/web/src/app/(site)/article/[slug]/page.tsx`: `generateStaticParams` + `dynamicParams = false`
  (unknown slugs get the export's 404), `generateMetadata` = `"<title> | <siteName>"` + summary as description.
- `features/articles/components/`: `ArticleDetail` (header, body, share, author card), `ArticleShare`,
  `ArticleAuthorCard`. Model: `buildArticleShareLinks`, `toReadingTimeLabel`.
- `shared/ui`: `HighlightedMarkdown` (async Server Component, react-markdown `MarkdownAsync` + remark-gfm +
  rehype-pretty-code), `CodeBlock` (figure with `title=` filename header + Copy), `CopyButton` (the only client
  component; used by code blocks and "Copy Link"), prose styles moved to `markdown-components.tsx` and shared
  with `Markdown`. `shared/lib`: `buildAbsoluteUrl(siteUrl, path)`, `toCodeBlockParts(figure)`.
- Dependencies pinned: `rehype-pretty-code@0.14.6`, `shiki@4.6.0`, `@types/hast@3.0.5` (dev).
- Fixture `seed-article-with-markdown` gained a fence without language and an escaped `1\.` paragraph.
- Tests: Playwright `e2e/article/*.spec.ts` (18 tests, `[story 2.4]`, page object `e2e/pages/article-page.ts`,
  `articlePage` fixture); Vitest for share links, reading-time label, absolute URL, code-block parts.

**Decisions**
- Shiki theme `dark-plus`: its surface/ink are exactly `code-surface` #1E1E1E / `code-ink` #D4D4D4;
  `keepBackground: false` so the surface comes from the token. Note for UX: token colours have hue, while
  DESIGN.md › Don'ts asks for no hues outside `destructive`; the mockup's sample is monochrome. If the UX
  owner wants a grayscale theme, only `PRETTY_CODE_OPTIONS.theme` in `HighlightedMarkdown.tsx` changes.
- `title="…"` meta is parsed by rehype-pretty-code itself; `toCodeBlockParts` reads its figcaption and the
  plain code for the Copy button. Fences without a language render as `plaintext` blocks (same frame + Copy).
- Highlighting runs only at build: no Shiki in `out/_next/static/chunks`.
- Copy buttons are `disabled` in the static HTML until hydrated (no dead control before JS, and no
  click-before-hydration race). Label turns into "Copied" for 2 s inside a polite live region.
- Share: Twitter/X `https://x.com/intent/tweet?url=…&text=<title>`, LinkedIn
  `https://www.linkedin.com/sharing/share-offsite/?url=…`; both open in a new tab with
  `noopener noreferrer`. Labels "Twitter"/"LinkedIn" as in the mockup, no icons (the mockup has none).
- Canonical URL = `buildAbsoluteUrl(settings.siteUrl, buildArticlePath(slug))`
  → `https://edgar-ferreira.com/article/<slug>/`.
- Author block and card read `profile.yml`: portrait, name, role; the card's bio line is `heroTagline`
  (the profile has no one-line bio; `bio` is multi-paragraph Markdown starting "Hello! I'm…").
- Author header block is a `section` named "Author" (Biome `useSemanticElements` rejects `role="group"`).

**Deviations**
- Reading time follows D3 (ceil(words/200) over the whole body): the real
  `oracle-apex-cloudflare-proxy-oauth` shows "6 min", not the mockup's "15 min" (mockup copy, not computed).
- `coverImage` is not rendered: the Artigo mockups have no cover, and no real article has one (the fixture
  does). Flag for UX if covers should appear.
- Blockquote got a `bg-secondary/40` fill (mockup); this also applies to `Markdown` elsewhere (About,
  project overview), which keeps prose consistent.

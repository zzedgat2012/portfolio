# Story 3.2: CI/CD

- Epic: Epic 3: SEO, delivery, cut-over
- Status: review

## Story

As the editor, I want every change checked and every merge to `main` deployed, so that Decap publishes go live without a developer.

## Acceptance criteria

1. Pull requests run lint, typecheck, unit tests (with content validation) and the e2e `@smoke` suite.
2. Pushes to `main` run the same checks with the full e2e suite, then `wrangler deploy` of `apps/web` (D5).
3. The deploy uses the repo secret `CLOUDFLARE_API_TOKEN`; without it the deploy is skipped with a warning, not failed.
4. Chromium is installed before building (CV PDF, D4).

## Dev notes

- Implemented by the orchestrating session in `.github/workflows/ci.yml`.
- `pnpm --filter web run deploy` (not `pnpm --filter web deploy`, which can resolve to pnpm's built-in `deploy` command).
- Deploys are serialized (`concurrency: deploy-production`); PR runs cancel superseded runs.
- Manual step for the owner: create a Cloudflare API token (Account › Workers Scripts: Edit; add Zone › Workers Routes: Edit on `edgar-ferreira.com` if routes are ever managed from CI) and run `gh secret set CLOUDFLARE_API_TOKEN`.
- The workflow is verified on GitHub at the first push (no local Actions runner).

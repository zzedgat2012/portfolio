# Story 2.3: Project page

- Epic: Epic 2: Pages
- Status: review

## Story

As a visitor, I want a page per project, so that I can see what it does and how it was built.

## Acceptance criteria

1. `/project/<slug>/` statically generated for every project (`dynamicParams = false`); unknown slugs 404.
2. Per `Projeto` mockups: "Back to projects" (`/#projects`), title (h1), tag chips, "View Demo" / "View Code" buttons only when URLs exist (external, `rel="noopener noreferrer"`), 16:9 cover with alt, Overview (Markdown body), Key Features grid, Technologies Used chips.
3. Page `<title>` `"<project> | Edgar Ferreira"` and description from summary.
4. Playwright specs from fixture projects (with and without demo/code links).

## Dev notes

- **Route:** `apps/web/src/app/(site)/project/[slug]/page.tsx` with `generateStaticParams` + `dynamicParams = false`; unknown slugs get the export's `404.html` (HTTP 404 under wrangler dev). The page renders inside the layout's `<main>`.
- **Component:** `features/projects/components/ProjectDetail.tsx` (server component), exported from `@/features/projects`. Back link, h1, tag chips (`TagList`), demo/code buttons only when the URL exists, 16:9 cover (`next/image`, `priority`), Overview (`Markdown`), Key Features grid, Technologies Used chips. Key Features and Technologies sections are omitted when their list is empty; each section is a `region` labelled by its h2.
- **Shared code for 2.4 / 2.5 / 3.1:** `shared/lib/build-page-metadata.ts` (`buildPageTitle`, `buildPageMetadata({ title, description, siteName })` returns `{ title: { absolute }, description? }`), and `shared/ui` `BackLink` (ghost button with arrow-left) and `ExternalLinkButton` (`primary` | `outline`, `target="_blank"`, `rel="noopener noreferrer"`). The site name comes from `settings/site` › `siteName`, the same source as the root layout's title template.
- **Tests:** Vitest `shared/lib/build-page-metadata.test.ts` (3); Playwright `e2e/project/{static-generation,content,links,metadata}.spec.ts` (16, 6 tagged `@smoke`), page object `e2e/pages/project-page.ts` registered as fixture `projectPage`. Existing fixtures already covered both-links, code-only and no-links cases, so no fixture content was added. All specs failed first on the missing route (404).
- **Deviations / notes:**
  - Button and back-link text use Open Sans (DESIGN.md `typography.button`); the Projeto mockup draws them in Fira Code. DESIGN.md wins for tokens; flag for `bmad-ux` to reconcile the mockup.
  - lucide-react 1.x has no GitHub logo, so "View Code" uses the `Code` glyph (same choice as the profile links).
  - The meta-description spec reads the served HTML, because a `<meta>` has no role to locate it by (AGENTS.md bans CSS locators).
  - No dependency added. `external/` not read.
